# BoxingDream

Scouting dossiers for boxing fight cards: every main-card bout side by side,
built from public fight records, with one pick per bout that is locked before
the opening bell and graded after the fight.

This repository is the published site, <https://boxingdream.github.io/>. Its
commit history is the public timestamp for every pick: `picks.jsonl` is the
append-only ledger, and a pick is committed here before its fight.
